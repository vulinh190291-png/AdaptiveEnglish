# AdaptiveEnglish

AdaptiveEnglish is an adaptive English learning platform based on a microservice architecture.

The system evaluates a learner's knowledge mastery through diagnostic assessments,
practice and quizzes, and dynamically recommends the next learning content based on
knowledge dependencies and mastery scores.

## Core Features

- Diagnostic assessment
- Knowledge mastery tracking
- Adaptive learning path recommendation
- Course enrollment
- English exercises and quizzes
- Teacher management dashboard
